# Codigo fuente de proyecto final de la maestria en sistemas informaticos
## API: 
Acceda a Swagger:
http://localhost:8080/api/swagger

## Ejecutar app

### Terminal
mvn clean install spring-boot:run

esto ya ejecuta la app en si, si quieres ejecutarlo desde tu IDE haz lo siguiente:


### VSCode
presiona F5 -> .vscode/launch.json define las configuraciones de ejecucion

### IntelliJ 
Importar proyecto y esperar a que cargue, click al boton de play
